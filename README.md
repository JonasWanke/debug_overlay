# debug_overlay

🐛 View debug infos and change settings via a central overlay for your app.

This repository is a pub workspace with the following packages:

| Package                                                     | Description                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------ |
| [`debug_overlay`](debug_overlay/)                           | The overlay, logs, media overrides, and the built-in helpers |
| [`debug_overlay_package_info_plus`](debug_overlay_package_info_plus/) | Package info tool (`package_info_plus`)                      |

See the [`debug_overlay` README](debug_overlay/README.md) to get started.
